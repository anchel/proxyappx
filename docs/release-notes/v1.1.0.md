## 中文

### 新功能
- **中英双语界面**：默认跟随系统语言，也可以在「设置 › 通用 › 语言」中切换为 English 或简体中文（重新启动 App 后生效）
- 网络扩展的日志和错误信息与界面使用同一种语言
- **安装包改为 DMG**：打开后把 ProxyAppX 拖到旁边的「Applications」快捷方式即可

### 改进
- 时长等信息按界面语言格式化；英文界面中的数量会区分单复数
- 系统扩展授权提示中的用途说明提供中英文版本

### 安装与升级
1. 下载 `ProxyAppX-1.1.0.dmg`，打开后把 `ProxyAppX` 拖到 `Applications`（**必须在 /Applications 下**）
2. 从「应用程序」中打开 ProxyAppX。从 1.0.0 升级时，App 会自动替换网络扩展，通常无需重新授权

系统要求：macOS 15 及以上。App 已用 Developer ID 签名并经 Apple 公证。

## English

### New
- **English and Simplified Chinese UI**: follows the system language, or choose English or 简体中文 under Settings › General › Language (applied after relaunching the app)
- The network extension's logs and error messages use the same language as the UI
- **The installer is now a DMG**: open it and drag ProxyAppX onto the Applications shortcut next to it

### Improvements
- Durations and similar values are formatted for the UI language, and counts in the English UI use proper singular and plural forms
- The usage description in the system extension approval prompt is available in English and Chinese

### Install or upgrade
1. Download `ProxyAppX-1.1.0.dmg`, open it, and drag `ProxyAppX` onto `Applications` (**it must live in /Applications**)
2. Open ProxyAppX from Applications. When upgrading from 1.0.0, the app replaces the network extension automatically, usually without asking for approval again

Requires macOS 15 or later. The app is signed with Developer ID and notarized by Apple.
